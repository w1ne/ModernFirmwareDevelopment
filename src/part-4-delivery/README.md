# Part 4: The Delivery (Outer Loop)

> "Amateurs talk strategy. Professionals talk logistics." — Omar Bradley

The "Inner Loop" (docker, unit tests) is about *developer velocity*.
The "Outer Loop" (CI, CD, Security) is about *organizational confidence*.

In this section, we discuss how to ship firmware at scale, compliant with regulations like the Cyber Resilience Act (CRA), without slowing down.
